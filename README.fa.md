# Persian Dub Hub — Doostiha Edition

افزونه‌ی Stremio برای کاتالوگ فیلم‌های دوبله‌ی فارسی از آرشیو عمومی سایت دوستی‌ها.

## ویژگی‌ها

- کاتالوگ فیلم‌های خارجی دوبله فارسی دوستی‌ها.
- کاتالوگ جداگانه‌ی انیمیشن‌های دوبله.
- جست‌وجوی نام فارسی و انگلیسی در صفحات آرشیو.
- نمایش پوستر، سال، خلاصه، امتیاز IMDb و مدت زمان هر جایی که سایت ارائه کرده باشد.
- ارائه‌ی لینک‌های MP4 منتشرشده با کیفیت‌های موجود مثل 1080p، 720p و 480p.
- ارسال Referer و User-Agent مناسب برای لینک‌های مستقیم، همراه با لینک بازکردن صفحه‌ی اصلی به‌عنوان راه جایگزین.
- بدون اشتراک، Debrid، API key یا Internet Archive.

## نصب و اجرا

پیش‌نیاز: Node.js نسخه 18 یا بالاتر.

```bash
npm install
npm start
```

سپس این نشانی را در Stremio از قسمت Addons و گزینه‌ی نصب با URL وارد کن:

```text
http://127.0.0.1:7000/manifest.json
```

این آدرس فقط برای همان دستگاهی است که سرور روی آن اجرا شده. برای Android TV یا دستگاه‌های دیگر، باید افزونه روی یک هاست HTTPS عمومی در دسترس باشد.

## منابع و نحوه‌ی پخش

افزونه فقط صفحات عمومی دوستی‌ها را می‌خواند و لینک‌های ویدئویی را که خود سایت در صفحه منتشر کرده است به Stremio می‌دهد. افزونه هیچ محتوایی را میزبانی، ذخیره یا بازنشر نمی‌کند.

در صفحه‌ی هر فیلم، لینک‌های MP4 منتشرشده می‌توانند به‌عنوان Stream مستقیم به Stremio ارائه شوند. اگر لینک مستقیم در دسترس نباشد، آیتم بازکردن صفحه‌ی اصلی نمایش داده می‌شود.

## نکته‌های مهم

- ممکن است برخی لینک‌ها به Referer نیاز داشته باشند؛ افزونه هدرهای مناسب را با قابلیت proxyHeaders ارسال می‌کند.
- اگر سرور دوستی‌ها برای IP کشوری خاص محدود شده باشد، افزونه آن محدودیت را دور نمی‌زند.
- در این نسخه هیچ توکن، حساب کاربری یا رمز عبوری از سایت دریافت نمی‌شود.
- آزمون‌های پارسر با فیکچرهای ساختگی انجام شده‌اند؛ اما پخش واقعی لینک‌ها در خود Stremio هنوز تست نشده و باید در شبکه‌ی شما بررسی شود.
